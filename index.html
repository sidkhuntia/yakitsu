How to Play

  • Type the word shown to strike the monster.
  • Every correct key knocks the monster back — fast typing buys you real time.
  • A wrong letter turns red. Backspace it out before you can finish the word.
  • Words get longer and monsters get faster each level. The pace is always beatable — it's a skill check, not a lottery.
  • Chain perfect words for a combo multiplier.
  • Mistakes make the monster surge. Lose a life if it reaches you. Run out and the run ends.
  • Press Esc to pause at any time.
